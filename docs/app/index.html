Kosto

Materiales, mano de obra, CIF y variaciones

3 a 40 caracteres: letras, números, punto o guion.
Mínimo 8 caracteres, con letras y números.

Versión web: funciona en Google Chrome. Puedes instalarla como aplicación con el botón de arriba o el ícono de instalar en la barra de direcciones. Los datos se guardan en este equipo.

Las cuentas nuevas quedan con rol Usuario. El administrador puede cambiar los roles.
